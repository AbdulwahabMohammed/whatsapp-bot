# خطوات الإعداد المحلي

توضح هذه الصفحة كيفية تجهيز البيئة اللازمة لتشغيل البوت على جهازك.

1. **تثبيت Node.js**
   - تأكد من وجود Node.js بإصدار 18 أو أحدث.
2. **إعداد متغيرات البيئة**
   - انسخ الملف `.env.example` إلى `.env` وأدخل مفاتيح OpenAI وبيانات PostgreSQL الخاصة بك.
3. **تثبيت الاعتمادات**
   ```bash
   npm install
   ```
4. **تشغيل خادم Redis محلي**
   - يحتاج طابور BullMQ إلى Redis بإصدار 6.2.0 على الأقل. يمكنك تشغيل نسخة متوافقة محليًّا عبر:
   ```bash
   docker run -p 6379:6379 redis:7-alpine
   ```
5. **تهيئة قاعدة البيانات**
  ```bash
  node src/initDb.js
  ```
  ينشئ هذا الأمر جداول المشروع بما في ذلك `conversation_stats` لقياس زمن الاستجابة.
6. **تشغيل فحص البيئة**
   ```bash
   npm run check-env
   ```
   يتحقق هذا الأمر من قدرة التطبيق على الاتصال بقاعدة بيانات PostgreSQL وبخادم Redis،
   كما يتأكد من وجود مجلدات جلسات واتساب (`auth-*`). عالج أي رسالة خطأ قبل المتابعة لتجنب توقف العامل لاحقًا.
7. **تحديد اللغة المفضلة لكل منشأة**
   - عند إنشاء منشأة جديدة من لوحة التحكم يمكنك اختيار حقل `Language` لتحدد
     اللغة التي ستُرسَل بها الردود تلقائيًّا.
بعد إتمام الخطوات السابقة يمكنك تشغيل المثال (`src/index.js`) لإضافة منشأة تجريبية وعرضها عبر:
```bash
npm start
```
