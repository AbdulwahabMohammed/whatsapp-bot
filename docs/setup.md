# خطوات الإعداد المحلي

توضح هذه الصفحة كيفية تجهيز البيئة اللازمة لتشغيل البوت على جهازك.

1. **تثبيت Node.js**
   - تأكد من وجود Node.js بإصدار 18 أو أحدث.
2. **إعداد متغيرات البيئة**
   - انسخ الملف `.env.example` إلى `.env` وأدخل مفاتيح OpenAI وبيانات PostgreSQL الخاصة بك.
3. **تثبيت الاعتمادات**
   ```bash
   npm install
   ```
4. **تهيئة قاعدة البيانات**
   ```bash
   node src/initDb.js
   ```
بعد إتمام الخطوات السابقة يمكنك تشغيل المثال باستخدام:
```bash
npm start
```
