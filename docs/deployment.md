# خطوات النشر على بيئة الإنتاج

تحتاج عملية نشر البوت إلى بعض الإعدادات المسبقة على الخادم المستهدف:

1. **تهيئة المتغيرات البيئية**
   - انسخ ملف `.env.example` إلى `.env` واملأ القيم المناسبة لمفاتيح OpenAI وقاعدة البيانات.
2. **تثبيت الاعتمادات**
   ```bash
   npm install --production
   ```
3. **تهيئة قاعدة البيانات**
   ```bash
   node src/initDb.js
   ```
4. **تشغيل البوت كخدمة**
   يمكن استخدام أدوات مثل `pm2` أو `systemd` لتشغيل الأمر التالي في الخلفية:
   ```bash
   npm run whatsapp
   ```
5. **مراقبة السجلات والتأكد من الاتصال بواتساب**
   عند أول تشغيل سيُطلب مسح رمز QR لربط الحساب.
