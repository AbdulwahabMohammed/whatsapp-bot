# بنية النظام

يحتوي هذا المشروع على عدة مكونات مترابطة لتنفيذ وظائف البوت:

## قاعدة البيانات
تُستخدَم PostgreSQL لتخزين بيانات المنشآت والمحادثات بالإضافة إلى معرّفات المساعدين والملفات المرجعية.

## خادم OpenAI
يتكامل البوت مع OpenAI API لإنشاء مساعدي الدردشة ومعالجة الرسائل.

## بوت واتساب
يعمل باستخدام مكتبة Baileys لقراءة الرسائل الواردة وإرسال الردود المناسبة حسب المساعد الخاص بكل منشأة.

## سكربتات CLI
توجد سكربتات ضمن `src/scripts/` تُستَخدم لإنشاء المساعدات ورفع الملفات المرجعية وربطها بالمساعد.

تتواصل هذه المكونات معًا عبر طبقة منطقية في مجلد `src/` لربط البيانات والخدمات وتقديم تجربة متكاملة للمستخدم.
