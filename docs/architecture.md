# بنية النظام

يحتوي هذا المشروع على عدة مكونات مترابطة لتنفيذ وظائف البوت:

## قاعدة البيانات
تُستخدَم PostgreSQL لتخزين بيانات المنشآت والمحادثات بالإضافة إلى معرّفات المساعدين والملفات المرجعية.
المخطط يشمل الجداول الرئيسية التالية:

- **organizations** لحفظ بيانات كل منشأة ومعرف المساعد الخاص بها، بما في ذلك
  التعليمات واللغة المفضلة للردود.
- **documents** لتتبع الملفات المرجعية المرتبطة بالمنشآت.
- **conversations** لتخزين رقم الهاتف وسِجل المحادثة مع كل عميل.
- **messages** لتخزين نصوص الرسائل المتبادلة بين المستخدم والمساعد مع الطابع الزمني.
- تحتوي الرسائل الآن على نوع المرفق ومساره المحلي إن وجد لتمكين عرض الصور والوثائق.
- **conversation_stats** لحفظ زمن الاستجابة لكل رسالة بالميلي ثانية لاحتساب متوسط سرعة الردود.

كما يضم المخطط فهارس لتحسين أداء الاستعلامات:
- فهرس على `messages(conversation_id)` لقراءة الرسائل الخاصة بمحادثة معينة بسرعة.
- فهرس على `conversations(customer_phone)` لتسهيل البحث عن المحادثة بناءً على رقم العميل.

## خادم OpenAI
يتكامل البوت مع OpenAI API لإنشاء مساعدي الدردشة ومعالجة الرسائل.

## بوت واتساب
يعمل باستخدام مكتبة Baileys لقراءة الرسائل الواردة وإرسال الردود المناسبة حسب المساعد الخاص بكل منشأة.

## سكربتات CLI
توجد سكربتات ضمن `src/scripts/` تُستَخدم لإنشاء المساعدات ورفع الملفات المرجعية وربطها بالمساعد.

تتواصل هذه المكونات معًا عبر طبقة منطقية في مجلد `src/` لربط البيانات والخدمات وتقديم تجربة متكاملة للمستخدم.
