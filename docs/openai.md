# استخدام عميل OpenAI

يعتمد البوت على مكتبة `openai` للتواصل مع واجهة OpenAI وإدارة المساعدات. تم تحديد الإصدار `^5.9.0` في ملف `package.json`، لكن الكود مهيأ للعمل مع عدة إصدارات من المكتبة.

بعض الإصدارات تصدّر الفئة `OpenAI` كقيمة افتراضية بينما إصدارات أخرى تقدّمها كمُصدّر باسم `OpenAI`. وللتوافق بين الإصدارات يستخدم الملف `src/openai.js` الشيفرة التالية:

```javascript
let OpenAI;
try {
  // يفضّل التصدير الافتراضي في الإصدارات الحديثة
  OpenAI = require('openai').default;
  if (!OpenAI) {
    ({ OpenAI } = require('openai'));
  }
} catch (err) {
  ({ OpenAI } = require('openai'));
}

const openai = new OpenAI({
  apiKey: process.env.OPENAI_API_KEY,
});
```

## إصدارات SDK المدعومة

تم اختبار المشروع اعتمادًا على الإصدار `5.9.0` من مكتبة `openai`، لكن الشيفرة أعلاه
تمكِّن البوت من العمل كذلك مع بعض إصدارات السلسلة `4.x` التي ما زالت توفِّر واجهات
`beta.assistants` و`beta.threads` ومتاجر المتجهات `beta.vectorStores` أو `vector_stores`.

## آلية الاستيراد المرنة

يعتمد الملف `src/openai.js` على تجربة الاستيراد الافتراضي أولًا ثم التصدير بالاسم
عند الفشل، ما يسمح بالتوافق بين الإصدارات المختلفة دون تعديل الكود.

## القيود والمتطلبات

- يحتاج البوت إلى توفر واجهة متاجر المتجهات في مكتبة OpenAI. سيظهر الخطأ التالي
  إذا كان الإصدار المستخدم يفتقدها:
  `This OpenAI SDK does not expose the vector store API. Please upgrade to a recent version.`
- يجب دعم مساحات `assistants` و`threads` ضمن `beta`، وإلا فلن تعمل ميزات المحادثة
  ورفع الملفات.

بهذه الطريقة يمكن تحديث مكتبة `openai` دون الحاجة لتعديل بقية أجزاء المشروع، مع بقاء الاعتماد على متغير `OPENAI_API_KEY` في ملف `.env` للوصول إلى واجهة OpenAI.

## منع تسرب تعليمات النظام

- قبل رفع أي ملف إلى متجر المتجهات يتم فحص محتواه. إذا طابق الملف نص التعليمات المخصصة
  للمساعد (أو التعليمات الافتراضية) يتم تجاهله وتسجيل تحذير بدلًا من إرساله إلى OpenAI.
- عند توليد الردود يتم التحقق من ناتج المساعد، وأي رد يطابق التعليمات النظامية يُستبدل
  برد افتراضي يحجب المحتوى الحساس عن المستخدم.
- يُنصح بعدم رفع ملفات تحتوي على تعليمات النظام والاكتفاء بتحرير الحقول المخصصة للتعليمات
  داخل النظام، مع الاعتماد على الفلتر التلقائي للحماية من التسربات غير المقصودة.
