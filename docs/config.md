# متغيرات البيئة

لضمان تشغيل البوت بشكل صحيح يجب ضبط المتغيرات التالية في ملف `.env`:

| المتغير | مثال من `.env.example` | الوصف |
|---------|-----------------------|-------|
| `OPENAI_API_KEY` | `your-openai-key` | مفتاح الوصول إلى واجهة OpenAI |
| `PGHOST` | `localhost` | عنوان خادم قاعدة البيانات |
| `PGUSER` | `postgres` | اسم مستخدم قاعدة البيانات |
| `PGDATABASE` | `whatsapp_bot` | اسم قاعدة البيانات المستخدمة |
| `PGPASSWORD` | `password` | كلمة مرور المستخدم |
| `PGPORT` | `5432` | منفذ اتصال PostgreSQL |
| `ADMIN_PASSWORD` | `your-password` | كلمة المرور المطلوبة لدخول واجهة الإدارة |
| `ADMIN_PORT` | `3001` | المنفذ الذي تعمل عليه لوحة الإدارة |
| `LOG_LEVEL` | `info` | مستوى رسائل السجل (`info`، `error`، وغيرها) |
| `MAX_RECONNECTS` | `5` | الحد الأقصى لمحاولات إعادة الاتصال بواتساب |

يتم تحميل جميع المنشآت تلقائيًّا من قاعدة البيانات دون الحاجة لأية متغيرات إضافية

قم بنسخ ملف `.env.example` إلى `.env` ثم عدل القيم بما يناسب بيئة النشر الخاصة بك.

يمكن أيضًا تحديد تعليمات مخصصة لكل منشأة تُستخدم عند إنشاء المساعد الخاص بها، وذلك من خلال واجهة الإدارة أو بإدراجها يدويًّا في جدول `organizations`.
