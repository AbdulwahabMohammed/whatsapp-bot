# متغيرات البيئة

لضمان تشغيل البوت بشكل صحيح يجب ضبط المتغيرات التالية في ملف `.env`:

| المتغير | مثال من `.env.example` | الوصف |
|---------|-----------------------|-------|
| `OPENAI_API_KEY` | `your-openai-key` | مفتاح الوصول إلى واجهة OpenAI |
| `PGHOST` | `localhost` | عنوان خادم قاعدة البيانات |
| `PGUSER` | `postgres` | اسم مستخدم قاعدة البيانات |
| `PGDATABASE` | `whatsapp_bot` | اسم قاعدة البيانات المستخدمة |
| `PGPASSWORD` | `password` | كلمة مرور المستخدم |
| `PGPORT` | `5432` | منفذ اتصال PostgreSQL |
| `ORGANIZATION_ID` | `1` | رقم المنشأة التي يخدمها البوت |

قم بنسخ ملف `.env.example` إلى `.env` ثم عدل القيم بما يناسب بيئة النشر الخاصة بك.
