# المساهمة في المشروع

نرحب بجميع المساهمات التي تساعد على تحسين البوت وتطويره. قبل إرسال طلب دمج جديد يرجى اتباع الخطوات التالية:

1. **إنشاء فرع جديد** يحوي التعديلات المقترحة.
2. **تشغيل الاختبارات** والتأكد من نجاحها قبل رفع التغييرات.
   لتشغيل الاختبارات استخدم الأمر:
   ```bash
   npm test
   ```
3. **تشغيل أداة lint** للتأكد من التزام الشفرة بالمعايير.
   لتشغيلها استخدم الأمر:
   ```bash
   npm run lint
   ```
4. **تحديث التوثيق** في مجلد `docs/` ليعكس أي ميزات جديدة أو تعديلات.
5. **تحديث سجل التغييرات** في `CHANGELOG.md` مع وصف مختصر للتعديلات.
6. عند الانتهاء، أرسل طلب الدمج مع وصف واضح للتغييرات التي قمت بها.
7. تفقد أحيانًا ملف `review_notes.md` في مجلد `docs/` فقد يتضمن ملاحظات من المراجعين
   ينبغي حذفها بعد تنفيذها.
8. يراقب الملف `.github/workflows/qodo-codex-auto.yml` تعليقات المراجعة من البوت
   `qodo-merge-pro[bot]`. إذا لم يجد أي تعليقات عند بدء التشغيل يصدر إشعارًا ثم
   يتوقف، ويُعاد تشغيله تلقائيًّا عند وصول التعليقات لاحقًا.

يساعد الالتزام بهذه التعليمات على تسهيل مراجعة التغييرات واعتمادها.
